```

│   ├── 团队协作可视化（实时 Agent 状态 + 协作流图）
│   ├── 项目启动器（可视化配置 + 模板）
│   └── 主题系统（暗夜玫瑰 + 更多主题）

├── 后端（增强）
│   ├── 会话聚合增强（跨 Agent 搜索 + 导入）
│   ├── MCP 市场（注册表 + 搜索 + 一键安装）
│   ├── 进程管理器（长运行进程监督）

    ├── 团队面板（实时 Agent 状态 + 角色 + 负载）

```

## 三、实施计划

### Phase 1：前端基础升级（最高优先级）
1. **富渲染引擎** - Markdown + KaTeX + Mermaid + 代码高亮
2. **命令面板** - Ctrl+K 全局搜索 + 快速操作
3. **UI 组件库** - 现代化按钮/卡片/对话框/表格
4. **动画系统** - 页面切换 + 状态变化 + 加载动画
5. **响应式布局** - 移动端适配

### Phase 2：核心功能整合
1. **团队协作面板** - 实时 Agent 状态 + 角色 + 协作流
2. **项目启动器** - 可视化配置 + 模板 + 实时预览
3. **MCP 市场** - 搜索 + 安装 + 配置
4. **会话增强** - 跨 Agent 搜索 + 导入 + 标签

### Phase 3：高级功能
1. **IDE 布局** - 可拖拽面板 + 文件树 + 编辑器
2. **进程管理** - 长运行进程监督
3. **隧道管理** - 暴露本地服务
4. **记忆系统** - SQLite FTS 全文搜索

### Phase 4：创新功能
1. **AI 工作流建议** - 基于历史数据的智能路由建议
2. **协作热力图** - 可视化 Agent 间的通信频率
3. **性能仪表盘** - 每个 Agent 的响应时间/成功率/DELTA 统计
4. **智能调度** - 基于负载的自动 Agent 选择
